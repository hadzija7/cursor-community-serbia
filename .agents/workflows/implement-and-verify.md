# Implement and Verify Workflow

## Purpose

Multi-step implementation with verification before marking work complete.

## Steps

1. **Implement** — Make changes following the relevant spec.
2. **Self-review** — Re-read the spec; confirm implementation matches.
3. **Run tests** — `pnpm test`
4. **Run lint** — `pnpm lint`
5. **Manual check** — Start dev server, verify key flows.
6. **Update docs** — `TODO.md`, `docs/quality.md`, `specs/README.md` as needed.

## When to Use

- Any feature or fix spanning multiple files.
- Work that touches shared components or APIs.
- Before closing a phase in `TODO.md`.
