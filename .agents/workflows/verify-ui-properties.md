# Verify UI Properties Workflow

## Purpose

Verify the web UI behaves correctly after changes.

## Steps

1. **Start dev server** — `pnpm dev`
2. **Check homepage** — Hero, events, ambassadors, partners load.
3. **Check subscribe** — Form renders, validation works.
4. **Check education** — Resources list, links open.
5. **Check favicon** — Cursor logo in tab.
6. **Check responsive** — Mobile layout reasonable.

## When to Use

- After layout or component changes.
- After content config changes.
- Before closing a phase in `TODO.md`.
